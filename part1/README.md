# Part 1 — Introduction to React

Source: https://fullstackopen.com/en/part1

Each exercise set is a separate Vite + React application.
Run any app with:

```bash
cd <app>
npm install
npm run dev
```

## Exercises

- **courseinfo (1.1–1.5)** — Final state after step 5: course + parts as a
  single object, `Header` / `Content` / `Total` components, `Content`
  renders three `Part` components. Only the final state is submitted.
- **unicafe (1.6–1.11)** — Feedback app (good/neutral/bad) with `Button`,
  `Statistics` and `StatisticLine` components, conditional
  `No feedback given` view, and statistics rendered in an HTML table
  (average + positive percentage, no console warnings).
- **anecdotes (1.12–1.14)** — Random anecdote button, voting stored in a
  copied array in state, and a section showing the anecdote with the most
  votes.
